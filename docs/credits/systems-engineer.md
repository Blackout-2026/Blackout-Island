# Credits (Systems Engineer and bunker art)

## Prototype gameplay audio (AU1)

Originally, all `Assets/Audio/Prototype/*.wav` were generated by `tools/generate-prototype-audio.py`
from this project's existing `prototype/src/audio/audio.js` synthesis recipes
(original source header: Systems Engineer, audio). This is an adaptation of
the project's prototype work; existing attribution is retained. No downloaded
recordings, external sound pack or new licence claim was introduced by AU1. The generated
audio does not use the separate, unfinished cinematic soundtrack. AU2 supersedes
30 of those outputs with the credited downloads below; the original prototype
attribution remains applicable to the 11 retained synthesized cues and AU1 code.
