## Weapon viewmodels

`Weapon_Smg_Visual`, `Weapon_Sniper_Visual` and `Weapon_Knife_Visual` are primitive placeholders built from the
prototype's own part sizes (`WeaponDefinitions`). To use a free low-poly mesh instead, import it as
`Assets/Models/Custom/SM_Weapon_<Name>.fbx` and run **Blackout > Art > Build Weapon Prefabs**; only the `Model` child is
replaced. The gloved hands and sleeves are part of the viewmodel, so a pack that has only the gun needs the hands added
(keep the placeholder's `Glove*` and `Sleeve*` parts, or model them in Blender).
